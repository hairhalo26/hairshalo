    Product Import

    Bring in a supplier's catalogue file. Products arrive as Draft for you to review, price, photograph and publish.

    1. Supplier and file

    Only upload files Hairshalo is authorised to use — a supplier's own export or a catalogue they have given you permission to sell from. Nothing is imported until you review it.

    2. Match the supplier's columns

    Each Hairshalo field takes one column from the file. Suggestions are filled in; anything you change is remembered for this supplier's next file.

    3. Pricing

    Supplier price → × exchange rate → + markup % → + fixed markup → rounding = Hairshalo price in ₹. You can override any product's price below. Supplier prices are stored separately and never become a selling price on their own.

    4. Categories

    Supplier categories are matched to Hairshalo categories by name where one exists. Choose one for anything unmapped, or create it. Nothing is created without you.
